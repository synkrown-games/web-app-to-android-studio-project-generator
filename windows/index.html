After you download

  1. Unzip it, then open the .sln file in Visual Studio 2022 (with the "\.NET desktop development" workload installed).
  2. Let NuGet restore Microsoft.Web.WebView2 this needs internet access the first time.
  3. Press F5, or build in Release. Your index.html loads from https://app.local/index.html, a virtual address backed by resources embedded in the exe.
  4. Relative paths and fetch() calls for CSS, scripts, and other assets work the same way they did in the browser, without any CORS errors.
  5. Anything that isn't HTML, JS, or CSS (models, textures, data files, other folders) is copied next to the exe in an AppAssets folder on every build. When you distribute the app, ship the whole output folder, not just the exe.
  6. Downloads and <input type="file"> pickers use WebView2's native dialogs, so they work out of the box.
  7. The machine running the exe needs the WebView2 Runtime, which already ships with Windows 11 and most Windows 10 installs.
  8. If you turned on Fullscreen, the window covers the whole screen with no title bar pair it with "Press Escape to close" unless your app already has its own way to exit.

The app icon is a placeholder unless you upload your own image.
